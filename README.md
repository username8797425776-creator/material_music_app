# This project created by GitHub Copilot.

This app is a Material 3 Android music player built on Flutter. It includes:
- search/music discovery using YouTube metadata APIs
- stream playback using YouTube media streams
- SponsorBlock segment skipping
- lyrics from Lyrics.ovh
- Material 3 UI with bottom navigation and player sheet

## Getting started

1. Install Flutter SDK.
2. Run:
   flutter pub get
   flutter run

> This repo is scaffolded for Android-only app development.
